# Features

Fluidd is packed with features to help you monitor, control, and manage your
3D printer. Here's an overview of what's available.

## Printing & Preview

<div class="grid cards" markdown>

- :lucide-printer:{ .lg .middle } **Printing**

    ---

    G-code viewer with multi-tool support, object exclusion, thumbnail
    previews, bed mesh visualization, and print history with statistics.

    [:octicons-arrow-right-24: Read more](printing.md)

- :lucide-upload:{ .lg .middle } **Slicer Uploads**

    ---

    Upload G-code directly from OrcaSlicer, PrusaSlicer, SuperSlicer, or Cura.

    [:octicons-arrow-right-24: Read more](slicer-uploads.md)

- :lucide-list-ordered:{ .lg .middle } **Job Queue**

    ---

    Queue multiple G-code files for sequential printing with drag-and-drop
    reordering and bulk actions.

    [:octicons-arrow-right-24: Read more](job-queue.md)

</div>

## Monitoring

<div class="grid cards" markdown>

- :lucide-thermometer:{ .lg .middle } **Thermals**

    ---

    Real-time temperature charts for heaters, fans, and sensors, with
    one-click thermal presets.

    [:octicons-arrow-right-24: Read more](thermals.md)

- :lucide-camera:{ .lg .middle } **Cameras**

    ---

    Support for MJPEG, HLS, WebRTC, and other streaming protocols from
    multiple cameras simultaneously.

    [:octicons-arrow-right-24: Read more](cameras.md)

- :lucide-gauge:{ .lg .middle } **Diagnostics**

    ---

    Customizable metrics dashboard with user-defined JavaScript collectors for
    tracking speeds, flow rates, and more.

    [:octicons-arrow-right-24: Read more](diagnostics.md)

</div>

## Control

<div class="grid cards" markdown>

- :lucide-terminal:{ .lg .middle } **Console**

    ---

    Command console with history navigation, autocomplete, clickable commands,
    and custom output filters.

    [:octicons-arrow-right-24: Read more](console.md)

- :lucide-square-code:{ .lg .middle } **Macros**

    ---

    Organize, categorize, and toggle visibility of your G-code macros.

    [:octicons-arrow-right-24: Read more](macros.md)

- :lucide-layers:{ .lg .middle } **Multi-Material**

    ---

    Multiple extruder support with Pressure Advance, plus Spoolman integration
    for filament spool tracking and QR code scanning.

    [:octicons-arrow-right-24: Read more](multi-material.md)

</div>

## File Management

<div class="grid cards" markdown>

- :lucide-folder:{ .lg .middle } **File Manager**

    ---

    Browse, upload, edit, and manage G-code files, configuration, logs, and
    more with search, previews, drag and drop, and bulk operations.

    [:octicons-arrow-right-24: Read more](file-manager.md)

- :lucide-file-text:{ .lg .middle } **File Editor**

    ---

    Built-in editor with syntax highlighting, CodeLens documentation links,
    outline navigation, and code folding.

    [:octicons-arrow-right-24: Read more](file-editor.md)

</div>

## System & Administration

<div class="grid cards" markdown>

- :lucide-keyboard:{ .lg .middle } **Keyboard Shortcuts**

    ---

    Navigate pages, control prints, and use the editor and console efficiently
    from the keyboard.

    [:octicons-arrow-right-24: Read more](keyboard-shortcuts.md)

- :lucide-refresh-cw:{ .lg .middle } **Updates**

    ---

    Automated updates for Klipper, Moonraker, Fluidd, and other components,
    with manual update instructions.

    [:octicons-arrow-right-24: Read more](updates.md)

- :lucide-bell:{ .lg .middle } **System & Notifications**

    ---

    Host information, service management, database backup, and alerts for
    throttling and pending updates.

    [:octicons-arrow-right-24: Read more](system-and-notifications.md)

- :lucide-shield-check:{ .lg .middle } **Authorization**

    ---

    JWT authentication with support for forced logins and LDAP.

    [:octicons-arrow-right-24: Read more](authorization.md)

- :lucide-network:{ .lg .middle } **Multiple Printers**

    ---

    Connect and switch between multiple printers from a single Fluidd
    instance.

    [:octicons-arrow-right-24: Read more](multiple-printers.md)

- :lucide-clapperboard:{ .lg .middle } **Timelapse**

    ---

    Browse, download, and manage timelapse recordings via Moonraker's
    timelapse component.

    [:octicons-arrow-right-24: Read more](timelapse.md)

- :lucide-languages:{ .lg .middle } **Localization**

    ---

    Available in multiple languages with automatic browser detection.

    [:octicons-arrow-right-24: Read more](localization.md)

</div>
